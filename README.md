# Module 10: UrbanStyle Customer Data Cleaning

This repository contains a Python script focused on data cleaning and preprocessing using the Pandas library for a retail customer dataset.

## Files Included
- `module10-assignment.py`: Python script performing data cleaning, type conversion, and basic business analytics.

## What I Practiced
- **Handling Missing Values:** Using median imputation for numeric data and forward-fill for dates.
- **Data Standardization:** Cleaning currency symbols, formatting phone numbers, and standardizing text casing for names and categories.
- **Type Conversion:** Converting strings to datetime objects and numeric types.
- **Feature Engineering:** Deriving new metrics like `days_since_last_purchase` and `purchase_frequency_category`.
- **Data Aggregation:** Grouping data to find revenue by loyalty status and top-performing categories.
